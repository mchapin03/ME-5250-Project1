# ME-5250 Robot Mechanics & Control Project 1
## Six-bar One-Dwell Mechanism

### How to Run
In python environment, run:

```pip install -r requirements.txt```

to download all necessary dependencies.

Then, to run all scripts and generate all plots and data, run:

```python3 run_all.py```

while in the folder containing the scripts. This can also be ran manually inside your IDE. All scripts can be run individually in the same way. Ensure that all scripts are in the same folder.
